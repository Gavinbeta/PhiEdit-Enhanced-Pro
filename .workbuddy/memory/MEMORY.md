# 项目长期约定

- 完成任何修改任务后，必须启动 PhiEdit 主窗口供用户查看，不能只报告构建或测试结果。
- 编辑区必须是真正的一块 `CanvasControl`，音符区与判定线区由同一画布分区绘制，不允许拆成两个独立画布再伪装。
- 参考源码放在 `reference/` 且保持 Git 忽略；只复用规则，不照搬原程序 1350×900 的固定像素常量。
- 界面禁止使用 Emoji。
- 版本号格式固定为 `[x].[y].[z]_BETA[i]`。`x` 只有用户明确要求时才变更；`y` 用于新增大功能；`z` 用于大功能的小功能追加；`i` 用于缺陷修复。每完成一个功能或修复都要按规则变更版本。当前版本为 1.2.2_BETA1。
